# Detection-Jumps-Methods-Toolbox-DJMT-for-MATLAB
The objective of the DJMT toolbox is to develop a set of functions in MATLAB programming for applying three well-known statistical tests for detection brakpoints in climate time series data: the Standard Normal Homogeneity Test (SNHT), the Cumulative Deviations Tests (CDT), and Worsley’s Likelihood Ratio Test (WLRT).
